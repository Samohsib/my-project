# 놀이 앱 모음 (만 10세)

아이패드 사파리에서 손가락으로 하는 놀이 앱 네 개입니다. 모두 빌드 없는 정적 웹앱이고, 실행 중에 바깥 인터넷을 쓰지 않습니다.

- 열기: https://samohsib.github.io/my-project/ (첫 화면에서 놀이를 고릅니다)

| 놀이 | 폴더 | 내용 |
|---|---|---|
| 반짝이 코딩 퍼즐 | `coding-puzzle/` | 순서 → 반복 → 나만의 블록 → 조건, 44판 |
| 조각조각 분수·소수 퍼즐 | `fraction-puzzle/` | 초4 분수·소수 8단원, 도전 모드 |
| 우리나라 지도 탐험 | `korea-map/` | 시·도 → 도시 → 명소·특산물 → 산·강, 도장 96개 |
| 논리 퍼즐 모음 | `logic-puzzles/` | 스도쿠·네모로직·부등호 퍼즐, 오늘의 퍼즐 |

앱마다 자세한 설명과 시험 방법은 그 폴더의 `README.md`에 있습니다. 앱을 고쳐 다시 올릴 때는 그 앱 `sw.js`의 캐시 버전을 올려야 홈 화면 앱이 새 파일을 받습니다.
